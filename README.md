# Shool-app

Минимальный онлайн-урок для двух участников: учитель и ученик работают с одним PDF и видят рукописные пометки друг друга в реальном времени.

## MVP

- две фиксированные страницы: `/teacher` и `/student`
- PDF загружает только учитель
- документ сохраняется в MongoDB GridFS
- оба участника видят один PDF
- стилус/мышь/палец рисуют поверх страницы
- штрихи синхронизируются через Socket.IO
- аннотации сохраняются по страницам
- учитель по умолчанию рисует красным, ученик синим
- ластик удаляет выбранный штрих
- undo удаляет последний собственный штрих
- после повторного входа документ и пометки восстанавливаются

## Локальный запуск

1. Установить Node.js 20+
2. `npm install`
3. Создать `.env`:

```env
MONGODB_URI=mongodb+srv://...
PORT=3000
```

4. `npm start`
5. Открыть:
   - http://localhost:3000/teacher
   - http://localhost:3000/student

## Railway

Приложение готовится под Railway. Для деплоя нужен только `MONGODB_URI`. PDF не хранится на локальном диске Railway, поэтому перезапуск контейнера не потеряет документ.

- [x] приватный GitHub-репозиторий
- [x] две роли: Teacher / Student
- [x] загрузка PDF только учителем
- [x] постоянное хранение PDF в MongoDB GridFS
- [x] просмотр одного документа обоими участниками
- [x] переход по страницам
- [x] рисование стилусом / мышью / пальцем
- [x] realtime-синхронизация штрихов через Socket.IO
- [x] постоянное хранение аннотаций
- [x] разные цвета по ролям
- [x] undo своего последнего штриха
- [x] ластик по штриху
- [ ] проверить Apple Pencil / Android stylus

## Phase 3 — только если реально понадобится

- [ ] несколько учебных документов

- [ ] несколько учеников
- [ ] комнаты/уроки
- [ ] история изменений
- [ ] голос/видео не включать, пока не появится реальная необходимость

## Критерии успеха MVP

1. Ребёнок пишет стилусом без заметных рывков.
2. Учитель видит штрих практически сразу.
3. Координаты совпадают на планшете и компьютере с разными разрешениями.
4. После закрытия вкладок и повторного входа PDF и пометки остаются.
5. Перезапуск Railway не уничтожает данные.
